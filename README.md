# CareFlow — UIKit Healthcare Clean Architecture
Portfolio-safe healthcare demo using **Swift + UIKit**, MVVM, Clean Architecture, Use Cases, Repository Pattern and Dependency Injection. The initial navigation is storyboard-based; feature UI is UIKit/Auto Layout. Data is mocked and contains no real patient or employer data.

## Architecture
Presentation → Domain/UseCases → Repository Protocol → Data Repository

## Highlights
- Storyboard navigation + UIKit controllers
- Constructor/protocol driven domain dependencies
- async/await mock data service
- Loading/error states
- Testable repository/use-case boundaries
